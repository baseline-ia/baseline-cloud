## Deviations from Design

1. **slug as PK**: The prompt scope explicitly stated `slug: text, primaryKey`. The design had `id: text PK`. Prompt wins.
2. **Schema columns**: Prompt specified `name` (not `displayName`), `disabledAt`, `disabledByUserId` — no `updatedAt`. Design had `displayName` and `updatedAt`. Prompt wins as authoritative scope definition.
3. **renameProject not implemented**: Slug-as-PK makes rename a delete+re-insert. Not in any PR scope.
4. **Test placement (PR 2)**: `tests/events.test.ts` is incompatible with this Next.js codebase. Enrollment tests placed in `lib/__tests__/events-enrollment.test.ts`.
5. **Admin UI form file name**: Design called the file `enroll-project-form.tsx`; prompt called it `projects-form.tsx`. The prompt explicitly used `projects-form.tsx` with `ProjectsForm` as the component name — prompt wins. The component covers both enroll and project-list actions in one file as specified.
